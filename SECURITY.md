# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the [Security tab](https://github.com/christopherrobin/Ironbolt/security) and choose **Report a vulnerability**. Don't open a public issue.

I'll acknowledge the report as soon as I can and keep you updated on the fix.

## Supported versions

Fixes land on the latest `main` and the most recent release.
